# 🧟 Survival 2D Zombie

A top-down 2D zombie survival game built with **Unity 6**.

Survive endless waves of zombies, rack up your score by killing enemies, and spend it on new weapons from the in-game shop — for as long as you can last.

---

## 🎮 Gameplay

- **Move** with `WASD`
- **Shoot / Attack** with `Left Mouse Button`
- **Switch weapons** with number keys `1–9`
- **Interact** with the GunMan NPC using `E` to buy weapons

Waves get harder over time — enemies grow in number and health. Stay alive!

---

## 🛠️ Built With

- [Unity 6](https://unity.com/) (6000.3.24f1) + Universal Render Pipeline
- Unity Behavior (Behavior Trees for enemy AI)
- Unity Input System
- TextMesh Pro
