## 🛠️ Tech Stack

- **Engine**: Unity 6000.3.24f1 (Unity 6)
- **Render Pipeline**: Universal Render Pipeline (URP)
- **Language**: C# (.NET Standard 2.1)
- **AI**: Unity Behavior (Behavior Trees)
- **Input**: Unity Input System (New Input System)
- **UI Text**: TextMesh Pro
- **Art**: Zombie Apocalypse Tileset
