## Teknologi

- **Engine:** Unity 6000.3.24f1 (Unity 6)
- **Render pipeline:** Universal Render Pipeline (URP)
- **Bahasa:** C# (.NET Standard 2.1)
- **AI:** Unity Behavior (Behavior Trees)
- **Input:** Unity Input System
- **Teks UI:** TextMesh Pro
- **Aset seni:** Zombie Apocalypse Tileset
